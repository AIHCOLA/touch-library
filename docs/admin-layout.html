The premise / 先定一个视觉判断

后台显得乱，
通常不是组件太多。

而是底色、层级和强调色没有先站队。先决定页面是浅是深、谁浮在上面、哪一个颜色有资格说话，再往里填内容。下面四种，拆开看都不复杂，难的是忍住不要全都用上。
